Instructions: Verifying Inheritance Test Cases Against the Rule-Engine Document
What You Are Doing
You are checking whether a set of test cases produce outcomes that match what the operative rules of the document specify. The test cases are verified against the rules, not against the conformance modules. The modules are quality-control artefacts for the document itself and must not be consulted to resolve any test.




Step 1 — Load the Document
Provide the rule-engine document (DOC00). Confirm it is accessible before proceeding.




Step 2 — Understand the Test Format
Each test has three components:




A label (e.g. FURUD-PARENTS-DESC-SON-ASABAH)
A heir composition (e.g. Wife + Son + Mother + Father)
A claimed outcome (e.g. 3/24; 13/24; 4/24; 4/24)




Step 3 — Identify the Operative Rules




The relevant sections are:




Part 0 to VIII
Appendices A–G — System-wide constraints, precedence rules, and interpretive discipline, as needed
Do not consult Appendix H. It contains the conformance modules — test scenarios, module IDs, input compositions, and recorded outcomes — which are quality-control artefacts for the document and carry no rule authority. In the tests, "Section" refers to DOC00; any reference to DOC01 is named as "DOC01 Clause" or "Schedule A (SA…)".




Step 4 - Await list of tests from user, once you finish reading these instructions, prompt the user to paste them
















Step 5 — Derive the Correct Outcome
Express each heir's share as a fraction of the estate. Normalise to a common denominator where needed.




Step 6 — Compare
Match each heir in the test to their derived share. If all shares match exactly, record PASS. If any share differs, record FAIL and state what the correct outcome is and which rule produces it.




Step 7 — Scope Limitation
Do not consult or apply anything from Appendix H. If a test outcome appears to depend on Appendix H, flag it as outside scope rather than attempting to verify it.




Step 8 — Report Results
For each section, record the number of passing tests and note any anomalies. At the end, provide a total pass count across all sections.
